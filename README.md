# Body Slots

Private initial extraction of declarative body-slot management from VRIK.

Body Slots owns definitions, stable keys, local placement and generic content policy. VRIK remains responsible for body binding, hand detection, interaction and presentation. Definitions are authored outside Skyrim; a visual editor is a future layer over the exported package contract.

This first development snapshot is not a released or game-tested mod. It contains newly written code; reconstructed VRIK code stays in its separate private repository.
